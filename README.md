# TechGuide Python Calculator

## About the Project
This is a Simple Calculator application developed using Python as part of the Tech Guide Python Programming Internship (Task 1).

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Handles invalid number inputs
- Menu-based calculator with an exit option

## Technologies Used
- Python
- Visual Studio Code

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python calculator.py
```
